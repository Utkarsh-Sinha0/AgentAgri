Executive position

One agent for the full agricultural solution loop.

AgriMesh is built around a practical thesis: a farmer's question rarely belongs to only one category. Crop health, weather, market timing, scheme access, finance, and previous actions all affect the right next step. AgriMesh brings these signals into a single evidence-checked workflow.

1/3

Food-system relevance

FAO reports that small family farmers produce around one-third of the world's food.

40%

Crop-risk urgency

FAO/IPPC reports that plant pests can destroy up to 40% of global crop production annually.

86%

Indian smallholder focus

India's Agriculture Census 2015-16 reports that small and marginal holdings form about 86% of operational holdings.

The more farmers use AgriMesh, the more useful its local memory becomes: observation, evidence, advisory, outcome, and stronger future context.

System workflow

From farmer signal to verified advisory.

This is the main end-to-end workflow implemented by the agent, shown as a clean spec-to-action pipeline.

Capture

Farmer sends text, voice, or a crop photo through Telegram, or views farm state through the PWA.

Understand

Gemma 4 analyzes crop images when present and classifies intent with grammar-constrained JSON.

Ground

Graph-Wiki retrieval collects crop, pest, scheme, and official reference evidence.

Call tools

Gemma 4 plans MCP calls for weather, mandi/MSP, schemes, finance, and crop knowledge.

Use memory

Field, crop stage, profile, NDVI, previous actions, and outcome atoms shape the response.

Verify

Safety, confidence, evidence indices, and memory contradictions are checked before delivery.

Workflow guarantee

AgriMesh is designed to cite or hedge, escalate when uncertain, avoid fabricated market/weather/scheme numbers, and never expose another farmer's raw details.

Evidence first

Official manuals, wiki articles, tool outputs, and memory atoms form the evidence bundle.

Tool-grounded facts

Weather, mandi, MSP, scheme, and finance data are retrieved from tool services.

Outcome learning

Advice outcomes strengthen or downgrade future memory through structured atoms.

Workflow specs by use case

The major farmer journeys.

Registration

Farmer and field setup

  1. /start opens language and welcome flow.
  2. /register captures name, phone, district, pincode, tehsil, and village.
  3. Field setup captures field name, area, soil type, crop, sowing date, and stage.
  4. The farmer can ask questions with active field and crop context.
Disease or pest

Photo to advisory

  1. Telegram downloads the largest crop photo.
  2. Gemma 4 vision produces a crop-health hypothesis.
  3. RAG retrieves crop and disease evidence.
  4. Weather and crop tools are called when relevant.
  5. Verifier gates safety, confidence, and contradictions.
  6. Advisory, evidence, and memory atoms are persisted.
Market decision

Sell, store, or wait

  1. Market intent is classified.
  2. Mandi prices and MSP context are fetched.
  3. Weather and storage context are considered.
  4. Gemma 4 reasons over tool facts.
  5. Verifier rejects unsupported numbers.
  6. Farmer receives a decision with confidence.
Outbreak intelligence

Local signal to alert

  1. Outcome such as worsened or no change is captured.
  2. Crop and threat are extracted.
  3. Reports cascade from village to pincode to tehsil to district.
  4. Threshold is 10% with a two-reporter floor.
  5. Cluster can notify relevant farmers and create public outbreak memory.
Finance

Cycle-level profit and loss

  1. /expense logs crop-cycle costs.
  2. /sale logs crop revenue.
  3. /finance summarizes active-cycle P&L.
  4. The dashboard displays finance context with farm history.
Data rights

Farmer-owned memory

  1. /mydata shows the farmer's own memory digest.
  2. /forgetme soft-redacts raw memory atoms.
  3. Aggregate learning remains k-anonymous.
  4. Other farmers' raw details are never exposed.

Safety, memory, and learning specs

How the agent gets safer and more useful.

Verifier checks

Before a reply reaches the farmer

Structural validity confirms selected action and warning indices resolve to real evidence. Contradiction checks compare advice with recent actions or outcomes. Calibration prevents HIGH confidence without enough evidence. Safety redirects risky pesticide, dosage, re-entry, and banned-chemical advice.

Memory graph

How use improves the system

M1 temporal decay favors recent field facts. M2 outcome boost strengthens advice that worked and downgrades failed advice. M3 causal chains connect observation, vision, advisory, and outcome. M4 k-anonymous learning allows community context only after privacy thresholds are met.
